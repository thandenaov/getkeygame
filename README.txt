GET KEY GAME - BẢN QUẢN TRỊ LINH HOẠT

1. Upload index.html, app.js, admin.html, admin.js lên thư mục gốc repo GitHub.
2. Trang chính: https://TENBAN.github.io/getkeygame/
3. Trang Admin: https://TENBAN.github.io/getkeygame/admin.html
4. Mật khẩu mặc định: minhwuan

Admin có thể:
- Đổi tiêu đề, logo, màu giao diện.
- Thêm/xóa/đổi tên/sắp xếp nhiệm vụ.
- Thêm/xóa/đổi tên/sắp xếp link mở khóa.
- Thêm/xóa/đổi tên/sắp xếp hướng dẫn.
- Tải logo/icon ảnh trực tiếp.
- Bật đồng hồ thật và tự đổi nền sáng/tối theo giờ.

Lưu ý: Dữ liệu Admin hiện lưu bằng localStorage nên chỉ áp dụng trên trình duyệt đã chỉnh. Muốn đồng bộ mọi thiết bị cần backend như Firebase.
