HƯỚNG DẪN

1. Mở index.html để xem trang người dùng.
2. Mở admin.html để quản trị.
3. Mật khẩu mặc định: admin123
4. Trong Admin có thể sửa tên, logo, màu, nhiệm vụ, link mở khoá, hướng dẫn và sắp xếp bằng kéo thả.
5. Sau khi sửa nhớ bấm “Lưu thay đổi”.

ĐĂNG LÊN HOSTING
- Upload toàn bộ file index.html, app.js, admin.html, admin.js vào public_html.
- Trang chính: tenmien.com
- Trang admin: tenmien.com/admin.html

ĐĂNG GITHUB PAGES
- Upload toàn bộ file lên repository.
- Settings > Pages > Deploy from branch > main > /(root).

LƯU Ý
Bản này là web tĩnh, dữ liệu Admin lưu bằng localStorage nên chỉ có hiệu lực trên đúng trình duyệt/thiết bị đã chỉnh. Muốn quản lý chung nhiều thiết bị cần backend hoặc Firebase.
